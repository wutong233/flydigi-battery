# 托盘图标

图标本身承担“报电量”的职责：颜色表示区间，长度表示剩余，数字给出**档位换算后的百分比**。

## 状态对照

| 状态 | 图形 | 颜色 | 提示文字 |
|---|---|---|---|
| 电量 0 / 1 / 2 | 电池 + `0` / `17` / `33` | 红 | `0% (0/6) · 无线` 等 |
| 电量 3 / 4 | 电池 + `50` / `67` | 黄 | `50% (3/6) · 无线` 等 |
| 电量 5 | 电池 + `83` | 绿 | `83% (5/6) · 有线` 等 |
| 电量 6（满电） | 满格电池，不画数字 | 绿 | `100% (6/6) · 无线` |
| 充电中 | 电池 + 百分比 + 亮绿凸点与底线 | 档位色 + 亮绿 | 同上 |
| 已连接、无电量 | 灰色电池 + `?` | 灰 | `已连接 · 电量不可用` |
| 未连接 | 灰色手柄 + 红色斜杠 | 灰 + 红 | `未连接` |

### 颜色

| 名称 | RGB | 十六进制 | 用途 |
|---|---|---|---|
| 红（0–2） | `231, 76, 60` | `#E74C3C` | 低电量 |
| 黄（3–4） | `241, 196, 15` | `#F1C40F` | 中电量 |
| 绿（5–6） | `46, 204, 113` | `#2ECC71` | 高电量 |
| 灰 | `150, 150, 150` | `#969696` | 未知电量 / 手柄 |
| 充电亮绿 | `120, 255, 140` | `#78FF8C` | 凸点、底部横线 |

分组逻辑集中在 `IconFactory.LevelColor`：

```csharp
if (level < 0) return UnknownLevel;
if (level <= 2) return RedLevel;
if (level <= 4) return YellowLevel;
return GreenLevel;
```

## 填充规则

- 比例：`FillFraction = level / levelMax`，0 档为 0，6 档为 1，其余线性。
- 方向：**从左往右**填充。`fw = round(innerWidth * frac)`，从内框左边开始画。
- 空电部分是同色系浅色（原色与白色按 45:55 混合），让黑色数字在整块电池上都可读；填充部分保持饱和色，0 档仍能靠边框颜色分辨红/黄/绿分组。
- 外框始终用档位亮色；数字为 3×7 点阵，16px 下 **1px 笔画、统一黑色**，无阴影。
- 图标内只显示两位数字：`0`、`17`、`33`、`50`、`67`、`83`。满电（`100%`）不画数字，用满格电池表示。
- 16px 下放不下 `%` 号，百分号只出现在悬停提示和详情里。

## 几何尺寸

设计栅格固定为 **16×16**，按实际图标尺寸整体缩放（`s = size / 16`）。电池比早期版本更长，16px 下内框为 13×10 像素。

**系统限制**：100% 缩放下，Windows 给每个托盘图标的槽位就是 16×16 像素；提供更大位图只会被系统缩回 16px。高 DPI 下槽位变为 20/24px，同一套渲染会自动适配。因此图标清晰度取决于字形与排版，而不是位图分辨率。

| 元素 | 计算 | 16px | 32px |
|---|---|---:|---:|
| 电池单元 `cell` | `max(2, round(2s))` | 2 | 4 |
| 文字单元 `textCell` | 从 `cell` 递减到能放进内框 | 1 | 2 |
| 电池高 `bodyH` | `cell*5 + 2` | 12 | 22 |
| 电池宽 `bodyW` | `min(round(15s), 可用宽度)` | 15 | 26 |
| 边框 `border` | `max(1, round(s))` | 1 | 2 |
| 凸点宽 | 16px 固定 1，其余 `max(2, round(1.8s))` | 1 | 4 |
| 凸点高 | `max(3, round(4s))` | 4 | 8 |
| 总宽（含凸点） | `bodyW + 凸点宽` | 16 | 30 |

- 两位数字在 16px 下各占 3px、间隔 1px，用 **1px 笔画**，整组 7×7 像素。
- 满电不画数字，所以不需要再塞第三位；`100%` 由满格电池表达。
- 电池体与凸点作为整体居中。16px 下横向占满 16px（电池 15 + 凸点 1），没有左右留白。
- 凸点位于右侧垂直居中；充电时凸点变为亮绿。
- 充电时还会在电池下方画一条亮绿横线（`by + bh + border`）。

实现位置：[`src/IconFactory.cs:94`](../src/IconFactory.cs#L94) `DrawBatteryCore`。

## 未连接与未知

- **未知**（`RenderUnknown`）：同样的电池形状，灰色、填充 0，数字换成 `?`；这个 `?` 保持白色，不跟随百分比数字的黑色。用于“手柄已连接但拿不到 7 档”。
- **未连接**（`RenderDisabled`）：抗锯齿绘制手柄机身 + 两个握把，白色描边，再叠一条白色光晕 + 红色圆头斜杠。
- `Render(status, size)` 的选择顺序：无状态 → 未连接；`ok=false` 或无设备 → `connected ? 未知 : 未连接`；设备无档位 → 同上；否则画电池。

## 托盘行为

- 图标尺寸取 `SystemInformation.SmallIconSize`（通常 16×16），小于 16 时强制 16。
- 图标缓存 key：`size:level:levelMax:plugged`；未知态是 `size:connected`，未连接是 `size:none`。只有状态变化才重新绘制。
- 左键单击：弹出详情气泡（电量、充电、连接、UID、更新时间）。
- 双击：同左键。
- 悬停提示最多 60 字符，格式为 `百分比 (档位/上限) · 有线|无线`，例如 `67% (4/6) · 无线`。
- 低电量气泡：`level/6 < 0.35` 触发一次，`< 0.15` 再触发一次；档位回升后重新武装。
- 右键菜单：立即刷新 / 查看详情 / 采样间隔（10、20、60 秒）/ 开机自启 / 退出。

## 图标文件

`assets/flydigi.ico` 由程序自己绘制并编码，包含 8 个尺寸：16、20、24、32、40、48、64、256。

- 每个尺寸都是 32bpp BGRA DIB，带 AND 掩码，兼容旧版 Windows。
- 256 尺寸按 ICO 规范写宽度/高度字节为 0。
- 构建时通过 `/win32icon:` 嵌入 exe，所以资源管理器、任务栏固定项也会显示正确图标。

```powershell
.\flydigi_battery.exe --preview .\icon_preview.png
powershell -ExecutionPolicy Bypass -File .\flydigi_tray.ps1 -Preview -PreviewPath .\ps1_icon_preview.png
```

预览表固定 10 列 × 5 行，深灰背景：

```text
列：0 17 33 50 67 83 满电 | 充电(67, plugged) | 未知(?) | 未连接
行：16px、20px、24px、32px、48px
```

第 7 列是满电状态：满格绿色电池，不画数字。

修改配色或几何后，先看预览图，再跑 `flydigi_battery.exe --selftest`。自检会逐档校验颜色、填充比例、百分比换算、满电图标文字留空、`67% (4/6) · 无线` 与 `100% (6/6) · 无线` 提示文案、45 张图标的非空像素，以及 ICO 编码。

C# 与 PS1 两套渲染器必须同步修改，否则两张预览图会不一致。
